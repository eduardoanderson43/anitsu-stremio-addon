# ☁️ Anitsu Cloud & Anime Filler Addon para Stremio

Servidor 24/7 de alta performance para o Stremio, integrando:
1. **☁️ Nuvem Anitsu [PT-BR]**: Acervo com 5.100+ animes com legendas e dublagens em português (Fansubs 1080p / BD), reproduzidos direto da nuvem sem torrents.
2. **🛡️ Guia de Fillers em Animes**: Indicador visual inteligente direto no Stremio que sinaliza se o episódio é **Cânon Oficial**, **Filler** ou **Misto**.

## 📺 Como Instalar no Stremio (TV, Celular e PC)

Após o deploy, sua URL será algo como:
`https://anitsu-stremio-addon.onrender.com`

1. Abra a URL no navegador do seu celular ou PC.
2. Clique no botão **"➕ Instalar no Stremio"** para adicionar o **Anitsu Nuvem** e o **Guia de Fillers**.
3. O Stremio abrirá automaticamente e sincronizará com a sua TV!

Ou copie os links diretos dos manifestos e cole na barra de pesquisa de addons do Stremio:
- **Anitsu Nuvem:** `https://SUA-URL/manifest.json`
- **Guia de Fillers:** `https://SUA-URL/filler/manifest.json`
